# BLW Campus Ministry East & Central Africa

A premium, production-oriented ministry platform built with React, Vite, Tailwind, Framer Motion, and a Node/Express backend foundation.

## Structure

- Client: React frontend with pages for Home, Live, Outreaches, Rhapsody, About, Give, Salvation, Connect, and an Admin Dashboard.
- Server: Express API skeleton with health endpoint for future database and auth integration.

## Run locally

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm start
```
